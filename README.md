# Kenneth Dela Torre — ITC C301 301I E-Portfolio

Static E-Portfolio for **Integrative Programming and Technologies (ITC C301 — 301I)** featuring Prelim, Midterm, and Finals works, including the **Motionary** capstone project.

## Structure

- `index.html` — Self-contained static site (HTML, CSS, JS, and embedded assets).

## Deployment (Vercel)

1. Push this repository to GitHub.
2. Import the repository in [Vercel](https://vercel.com/new).
3. Keep the default settings (**Framework Preset: Other**, no build command, root output directory) and click **Deploy**.
